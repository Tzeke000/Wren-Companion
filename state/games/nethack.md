## Notes

NetHack is text-based — the entire game state renders as ASCII to a terminal
window. That makes it ideal for me: I can `focus_window` the NetHack terminal,
screen_grab to read the map, type keystrokes to act. Save files persist between
sessions, so my character carries over.

## Conduct tracking

NetHack tracks "conducts" — self-imposed restrictions that show in the death
screen. Examples:
- vegetarian: no animal corpses
- vegan: no animal products at all
- atheist: never pray
- pacifist: never hit anything
- nudist: never wear armor

Early goal: no conduct yet, just learn the game. Later: pick one and run with it.
