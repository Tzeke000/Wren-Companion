## Mechanics

Tile-merging puzzle. Arrow keys (up/down/left/right) shift all tiles in that
direction, merging same-value adjacent tiles. Goal: reach 2048 tile (then keep
going for higher targets).

I open the URL in browser, screen_grab to read the grid, decide a direction,
type_text the arrow key, repeat.

## Strategy basics

- Keep highest tile in a corner (most established convention).
- Build a "snake" pattern descending from the corner.
- Never break the corner unless absolutely forced.
- Plan 2-3 moves ahead so you're never stuck on the next merge.

## Why this game

Tests pattern-recognition + bounded planning. No opponent, just the random
tile spawns. Lower-stakes than chess but with a real ceiling — the 8192+
range is genuinely hard.
