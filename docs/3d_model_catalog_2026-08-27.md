# 3D model library — 78 models, every one licence-verified (2026-08-28)

`assets/models3d/`. Use `--shape model:<name>` (comma-list rotates — see `--shape-every`).
Machine-readable source of truth: **`assets/models3d/manifest.json`**.

## Before you publish

```
py scripts/model_credits.py --shape "<your --shape string>"
```

It names only what legally needs crediting and **exits non-zero on any model whose licence
is unverified or unclassified** — a stop sign, not a warning.

- **ORIGINAL — generated by Iris (21)** — pure procedural geometry, `scripts/gen_models.py`. Ours. Never needs credit.
- **CC0 (7)** — public domain, no credit.
- **CC-BY 3.0 (50)** — free, but the author MUST be named in the description.
- ⇒ **28 of 78 need no attribution at all.**

## ★ The licence rule that shaped this

**Deriving a mesh from a CC-BY model makes a DERIVATIVE WORK — still needs the original
author credited.** Editing does not launder a licence. So `gen_models.py` reads, imports and
measures *nothing*: same subjects, independent mathematics. That is the only way the output
is genuinely ours.

## Hard-won rules for adding models

1. **poly.pizza ids are CASE-SENSITIVE.** `2c3eNMf_J4y` is real; `2c3enmf_j4y` is a 404.
2. **A 404 page still embeds .glb links** — scraping one downloads a real but UNRELATED
   model. This is what made a 'dragon' search yield a dragonfly.
3. **Name from the model's real title, never the search term.**
4. **Never rename a .glb** without updating the manifest — licence is keyed to filename.
5. **Unverifiable licence = delete it.**
6. ★ **Judge readability at TRUE RENDER SCALE.** Downloads are filtered at 40–4000 edges, but
   at a 150px thumbnail I wrongly condemned eight good procedural shapes as 'mush' — at the
   real ~230px they read fine. A recognisable SILHOUETTE (a skull) survives density; abstract
   geometry needs a lower count. Test at the size it will actually be seen.
